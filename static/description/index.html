Key Advantages

Why POS Payment Reference?

Engineered for high cashier throughput, non-intrusive UI ergonomics, and complete accounting audit trails.

Smart Non-Cash Targeting

Intelligently excludes cash payment methods (!is_cash_count), displaying the reference button only on electronic transfers, cards, and checks where references are necessary.

Owl TextInput Modal

Built with Odoo 19's native TextInputPopup and makeAwaitable dialog architecture, guaranteeing smooth animations and touch-screen responsiveness.

Dynamic Visual Feedback

Displays a crisp green badge with the reference number when configured (btn-success) and a subtle outline button (btn-outline-secondary) when pending.

Per-Line Split Tracking

Enables split orders with multiple non-cash tenders to each store their own unique transaction voucher, check number, or bank confirmation ID independently.

Frictionless Bank Reconciliation

Eliminates end-of-day discrepancy headaches. Accountants can cross-match POS journal entries with bank statements using exact reference numbers.

Clean, Non-Intrusive Layout

Keeps the payment screen clean and unbloated by placing the compact action button directly inside the payment line container next to line amounts.

How It Works

4-Step Cashier Workflow

Simple, intuitive flow that requires zero special cashier training.

1

Select Non-Cash Method

In POS payment screen, select Bank, Card, Check, or Account method.

2

Click Reference Button

Click or tap the # Reference button on the payment line.

3

Enter Reference in Popup

Type the transaction code or check # in the modal and click Confirm.

4

Validate Order

The button turns green showing the reference. Click Validate to finish.
